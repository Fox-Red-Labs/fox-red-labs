Blink your LP-MSPM0L1306 from this page

Plug the board in and press one button. The page saves what is on the board, writes TI's LED example to it through the board's own debugger, then times the LED to prove it worked. Nothing to install.

This browser cannot reach USB devices.

Open this page in Chrome or Edge on a Mac, Windows or ChromeOS computer. Safari, Firefox and phones do not offer it. Or skip the browser and use the terminal route below.

You need: the LP-MSPM0L1306 LaunchPad kit as it came (its jumpers on) and a USB cable that carries data, plugged into the connector on the top half of the board, straight into the computer.

Chrome asks which device to use. Pick XDS110 … CMSIS-DAP; with other boards plugged in, unplug them first, since every XDS110 has the same name there. The page asks for a place to save a copy of the board's flash (about 90 KB) before it writes anything.

    Go further

    Change the pattern, print your own message, or build anything else on this board. This page only flashes the one prebuilt demo; building needs TI's free tools on your computer. Two ways in:

    In a terminal (Mac or Linux): clone the project and run its one command. It lists what to install, with sizes, before anything else.

    git clone --depth 1 --filter=blob:none --sparse https://github.com/Fox-Red-Labs/fox-red-labs.git
cd fox-red-labs
./start.sh mspm0l1306 blink

    With an AI assistant (Claude Code or Codex): paste this, and it walks you through the same steps, asking before it installs anything.

    Set up my TI LaunchPad with Fox Red Labs. Run git clone --depth 1 --filter=blob:none --sparse https://github.com/Fox-Red-Labs/fox-red-labs.git, then read fox-red-labs/START.md in full and follow it. Ask me before installing anything or writing to the board. It is an LP-MSPM0L1306.

    Put back what was there

    Choose the copy this page saved. It goes back only onto the board it came from.

      If something goes wrong

      You seeDo this
      The device list is emptyUse a cable that carries data (a charge-only cable powers the board but hides it), in the top connector, straight into the computer, not a hub.
      "this board's chip reports DEVICEID …"The board is not an LP-MSPM0L1306, and nothing was written. This page flashes only that board.
      "the chip's debug port did not power up"The program on the board may be in a deep sleep. Hold S1, press and release S3, keep S1 held two more seconds, then press the button again at once.
      The check says the LED did not follow the patternLook at the board: LED2 should flash red twice, then pause. Check the LED2 jumpers (J2, J3, J12, J13) are on. Then flash again.
      "the debugger stopped answering"Unplug the board, plug it back in, reload this page and try again.
