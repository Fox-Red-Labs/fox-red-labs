I have a TI LaunchPad development kit; its name is on the board's silkscreen. Clone https://github.com/Fox-Red-Labs/fox-red-labs with `git clone --depth 1 --filter=blob:none --sparse https://github.com/Fox-Red-Labs/fox-red-labs.git`, then `git sparse-checkout add tools data` plus the folder named for my board (the table in START.md maps board names to folders). Read that folder's README.md, AGENTS.md and FAQ.md, then build, flash and run its blink with the commands there. Ask me before any step that needs my hands, and show me the serial output when it runs.
