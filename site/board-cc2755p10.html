LP-EM-CC2755P10 (CC2755P10)

The CC2755P10 is a wireless microcontroller in TI's CC27xx family: 96 MHz Arm Cortex-M33, 1 MB of flash, 162 kB of RAM, BLE 6.0, Zigbee 3.0, Thread, Matter.

Get it running

First blink: 41 s from plug-in to a changed blink (terminal).

  1. Copy TI's empty example.

    cp -R <SDK>/examples/nortos/LP_EM_CC2755P10/drivers/empty .

  2. Build it.

    make -C empty/ticlang SIMPLELINK_LOWPOWER_F3_SDK_INSTALL_DIR=<SDK> SYSCONFIG_TOOL=/Applications/ti/sysconfig_1.26.3/sysconfig_cli.sh TICLANG_ARMCOMPILER=/Applications/ti/ccs2101/ccs/tools/compiler/ti-cgt-armllvm_5.1.1.LTS

  3. Flash the .hex with UniFlash. Leave out -v and any chip erase.

    /Applications/ti/uniflash_9.6.0/dslite.sh --mode flash -c cc2755p10/CC2755P10.ccxml -e -f -u empty/ticlang/empty.hex

Replace the parts in angle brackets. Run it from the terminal in VS Code, CCStudio or any IDE.

You should see: the red LED (DIO16) toggles once a second. Change the sleep time in empty/empty.c, build and flash again.

Fixes

  • If you see FRL-E099 FAILED: KeyError: 'deviceid' from frl identify --board cc2755p10, use frl identify --probe <serial>; it names the chip (CC2755P105E0WRHAR).
  • If you see the portable app on this board (TI Drivers), build with portability/three-ways/tidrivers/build_cc2755p10.sh (SysConfig 1.28.0 here).
  • If you see a port copied from the CC2340R5 runs (CPU spins at the right place) but the console prints nothing, use CONFIG_GPIO_LED_0 and CONFIG_GPIO_LED_1 (DIO16 red, DIO12 green) from ti_drivers_config.h, never a literal index.
  • If you see Arduino Blink or MicroPython v1.29.0 through TI's Zephyr fork (v3.7.0-ti-1.00.01_ga), use the bare-metal route (ports/ulisp/boards/cc2755p10/) or port the board file to an upstream Zephyr 4.x tree.
  • If you see Failed: Unknown Property: FlashEraseSetting from dslite flash -s FlashEraseSetting=Chip Erase on this chip, leave the setting out: the default erase is what restore.sh uses.
  • If you see frl blink check fails FRL-E040 ... stayed at one level though the LED blinks, update tools/frl/lpf3.py: reads now sleep an uneven 0 to 1.4 s apart, up to 16.
  • If you see Error -2001 right after a TI example such as zigbee/rf_test ran, with debug authentication "not required", unplugging the probe's USB for ten seconds is not run; docs/remote-board-recovery.md shows how to read the boot status.
  • If you see undefined node label 'boosterpack_spi' from west build --shield ti_bp_cc140xp, build with no --shield; pass -DEXTRA_DTC_OVERLAY_FILE=ports/cc1407p-zephyr/boards/lp_em_cc2755p10.overlay.
