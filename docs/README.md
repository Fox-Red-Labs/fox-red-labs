# Docs: methods, guides and experiments

Where to start: `methodology.md` (how a number is measured and recorded), `vocab.md` (every term), `frl.md` (the setup tool), `hardware.md` and `parts-catalog.md` (what to buy), `ports.md` (every port), `builds/` (one Markdown file per project, with its steps), `experiments/` (one page per "would this work?" attempt, failures included), and `guides/`.

Most of the weight is pictures (about 240 MB), so a sparse clone leaves this folder out; read one page with `git show HEAD:docs/<file>`. Board READMEs follow `readme-standard.md`.

Private planning lives beside the reader docs and never exports: `roadmap.md` (every thread), `next-session.md` (the hand-off), `arrivals/` (one plan per board on order), `research/` (one dated note per open thread) and `archive/` (closed notes, moved there at the sweep when nothing links to them any more; `archive/research/` holds the research ones). A note belongs in `research/` only while its thread is open.
