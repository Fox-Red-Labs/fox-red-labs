# Can a TI LP-MSPM0C1104 LaunchPad development kit, with 1 kB of RAM, run a neural net that reads handwritten digits?

**Short answer.** Yes, the smallest one. BitNetMCU's 1k model (7.2 kB of code, 804 B of RAM with its stack) read all 10 of the library's test digits right on the board, giving the same answers as on a Mac (3209069277). The 16-channel CNN links (13.4 kB of code) but its stack runs past the start of RAM and it never finishes.

Terms: [vocab](../vocab.md) (CNN, inference, stack). Errors and fixes: [LP-MSPM0C1104 FAQ](../../mspm0c1104/FAQ.md). 1 kB = 1,024 bytes.

**Question.** BitNetMCU is an open handwriting recognizer built for 10-cent chips. Does any of its models run in the 1 kB of RAM on the MSPM0C1104?

**Vendor position.** Not a TI example. The author's repository targets WCH RISC-V chips with 2 to 4 kB of RAM. The MSPM0C1104 data sheet (SLASF90E) lists 1 kB of SRAM and 16 kB of flash.

**What was tried.** BitNetMCU commit `0715bfc`, unchanged in `third-party/bitnetmcu/`, this repo's MSPM0 harness `ports/bitnetmcu/mspm0/main.c`, TI Arm Clang 5.1.1 -O3, 24 MHz, MSPM0 SDK 2.11.00.07. Each image was flashed with OpenOCD and read back after 4 to 60 seconds, 2026-10-08.

**How far it got.**

| Model | Code | RAM (with 700 B stack) | Result |
|---|--:|--:|---|
| 1k | 7.2 kB | 804 B | 10 of 10 digits right |
| 16-channel CNN | 13.4 kB | 804 B | does not finish: stack pointer at 0x1FFFFE18, below RAM |
| 12k | | | does not link: 928 B of flash free when it was placed, `.text` 4.5 kB beyond it |

Cycle counts were not measured: the chip has no working SysTick, which the harness uses.

**The line.** The 1k model fits with 220 B of RAM to spare. The 16-channel CNN needs more than the 700 B stack it was given, and the chip has 220 B more at most.

**Ask.** If you have run a neural net in under 1 kB on an MSPM0, say what you used.
