One page per "would this work?" attempt on a TI board, starting with the LP-EM-CC2340R5. Each page gives the exact place a combination stops, the reason, and what to try next. A page that reaches a working result says so first.

## How to add one

1. Copy any page here. Keep the `<!-- experiment -->` block at the top: `id` (E and the next free number), `board`, `date`, `status` (`works`, `line found`, `in progress` or `waiting`), `reached` (the last step that passed: configure, compile, link, flash, boot, run, verified), `line` (one sentence, with the number) and `stop` (why it stopped, so the site can tag it: `ram`, `flash`, `cpu`, `no-software`, `tools`, `radio-link`, `ours`, `unknown`, or `none` when nothing stopped it). An optional `page: none` line means the page ships as a repository document and is on no project page.
2. Fill the seven sections below.
3. Add its row to the index table here.
4. `python3 tools/render_experiments.py`, then `python3 tools/site_check.py` must print OK.

## The format

Every experiment page has these sections, in this order:

1. **Question.** One sentence a builder would ask.
2. **Vendor position.** What the vendor's docs say, quoted, with the source and date.
3. **What was tried.** Board, SDK and tool versions, the changes made (as a diff in the repo), commands.
4. **How far it got.** Configure, compile, link, flash, boot, run, measured. Stop at the first step that failed.
5. **The line.** The exact limit in numbers (bytes over, percent done, error text) and the cause.
6. **Next moves.** Concrete ideas for a reader: trim a heap, compress, a different part, a different stack version, a different radio path.
7. **Limits.** What the page does not show.

When the vendor ships no example for the chip (the combination is a first), the page says so under **The line**: what existed (the nearest vendor examples and documents), how it was done, a table of what went wrong with its cause tag, cost and fix, the effort (elapsed time, board runs, hands needed, tools added) and a plain verdict on how good or bad it was.
